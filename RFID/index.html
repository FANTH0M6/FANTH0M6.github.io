产品介绍

RFID 企业套件是一套射频识别（RFID）系统，能够实时监控货物、容器、人员、资产等的移动而无需人工干预，并可以通过开放平台提供的 API 和开发包，轻松地与任何 ERP、WMS、MES、业务管理软件或任何其他应用程序集成。套件中集成了RFID标签和各型读写器，为用户完成连接硬件并收集数据，通过预置的轻量级业务功能模块，快速实现基于 RFID 的物流容器管理、库房管理、产品追溯、固定资产管理、盘点等应用。

产品功能

  • RFID 电子标签

    采用出色且合适的芯片、场景化的天线设计，为消费品、鞋服、家电等行业设计的高性价比RFID电子标签。

  • 企业平台

    企业平台将每个设备、资产、商品连接到统一的可扩展的企业级平台,实现RFID全连接。

  • EPCIS信息服务

    为商家和品牌方提供基于RFID的供应链信息和增值服务，放大一物一码价值，打通供应链信息孤岛。

产品优势

  • 极小缝隙天线技术

    保障密集码托、密集存储、密集堆放场景的识别率

  • 全向稳定增益技术

    保障在复杂场景下，多方向上识别率一致

  • 小面积金属抗干扰技术

    保障在各种产品上使用时的性能一致，避免小型金属件带来的影响
