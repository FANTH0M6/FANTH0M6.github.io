产品介绍

京东物流智能仓储执行系统（Warehouse Execution System, 以下简称 WES）聚焦医药、消费品、3C、能源四大主流行业，重点支持千平米以上，机器区为主、兼顾人区的自动化仓库场景。WES 适配由简单到复杂的主流自动化业务场景，通过丰富易用的模块化功能、智能协同的任务中心、灵活的二开和数据交换平台，为企业提供智能化解决方案，帮助企业实现仓储的高效运行和降本增效，全面助力企业的数字化转型和智能化升级。

产品功能

  • 主数据模块

    多仓库多货主下灵活权限管理；智能化柔性化工作站管理；灵活、高可用的打印能力；丰富可扩展的商品管理策略

  • 入库模块

    支持灵活配置入库流程；对接产线自动码盘；多策略组合推荐；支持药品验收管控拦截

  • 出库模块

    多样化、智能化出库策略，全方位满足业务诉求；智能算法助力出库策略最优；支持多种主流的作业模式，操作轻便易上手；流程灵活多样，适配丰富业务场景

  • 在库库存模块

    多设备、多类型、多形态高效盘点；智能算法推荐自动理货；多维度库存及可视化报表，多种预警策略；多类型、多参数策略补货和移库；先进的药品养护管理

服务优势

  • 智能协同中枢 任务中心

    站在全仓的角度解决多种任务之间的调度，灵活配置组装，保证仓内各作业任务有条不紊;覆盖仓储作业主流环节的智能任务协同，包含收货、上架、拣货、分播、复核、盘点、理货;通过算法智能调度各类任务，使仓库运行实现全仓最优和效率最大化

  • 更便捷智能的数据交换平台

    集成更轻量级的数据交换平台（EDI），沉淀共性接口，将对接过的业务共性部分进行组件化，可大幅降低接口联调工时；可链接各种主流上游系统,保证数据交换的高效性与便捷；支持对接京东物流自研多种上下游系统与多种三方 WCS(仓储控制系统)、RCS(机器人控制系统)

  • 适配多种场景 + 支持二次开发

    WES 可涵盖行业常见场景和行业共性所需功能，聚焦机器区典型场景，兼容立库、天狼、地狼、机械臂等多种主流自动化设备；支持二次开发，大幅降低定制化开发成本，提供5种主流场景的二开解决方案，如：业务流程规则策略的定义和配置，自定义报表，开放 API（应用程序接口），商品及单据的自定义扩展属性，页面元素可配置等；模块化设计，可根据需求选择功能模块，真正实现积木化拆装

  • 界面简单易用 可视化强

    界面操作简单易用，灵活适配现场多种主流自动化设备场景，提供人性化和多元化的人机交互设计，大幅降低人员学习成本；采用业界先进的设计理念，统一界面 UI 框架，可扩展性强，支持灵活定制可视化看板及智慧大屏
